Magento 2 Developer Take-Home: Currency

Exchange Converter

Build a custom Magento 2 module that adds a storefront page with a currency exchange converter.
The page should allow a buyer to select any currency supported by Frankfurter as the From
currency and the To currency, view the current exchange rate, and see how that rate has moved
over time.

The user should also be able to swap the selected currencies using a swap control.

API documentation: https://frankfurter.dev

Must-have


A storefront currency converter page

Current exchange-rate lookup

Historical chart
